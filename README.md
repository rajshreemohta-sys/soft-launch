# Account Signal Monitor

Watches live news for ~40 B2B accounts, uses Gemini Flash to spot trigger events, scores accounts, and emails a twice-weekly Hot List. Built with Next.js, Supabase, Gemini Flash, Resend and Vercel.

> Demo project. Companies and news are real; Arjun, his product and all deal notes are fictional. Built for a Mesa School of Business exam project.

Work in progress. Setup steps, architecture and the Components Map will be added as the build progresses.

## Local development

```bash
cp .env.example .env.local   # then fill in values
npm install
npm run dev
```
